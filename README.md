# Hotel Booking System

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](https://opensource.org/licenses/MIT)

## Overview

The system will facilitate seamless hotel reservations, integrate with a payment gateway for online payments in Nigerian Naira (NGN), and include a link to the NBTE Consult main website. Development will utilize Node.js for the backend and React.js for the frontend, ensuring scalability, performance, and maintainability.

## Installation instructions

```bash
composer install
```

```bash
cp .env.example .env
```

```bash
php artisan key:generate
```

```bash
php artisan migrate
```

```bash
php artisan db:seed
```

```bash
php artisan serve
```
